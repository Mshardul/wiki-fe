Inside Pod Resource Limits

Every container has a request and a limit for CPU and memory. The scheduler uses requests once, to decide where a pod fits. The kernel enforces limits all the time, through cgroups on the node. Each gauge shows usage as a bar, the request as a dashed line and the limit as a solid red line.
