Inside Postgres MVCC

Postgres never updates a row in place. Every UPDATE writes a new version (a tuple) stamped with the transaction that created it (xmin), and stamps the old one with the transaction that ended it (xmax). Step through to see who can see which version, and when vacuum is allowed to clean up.
